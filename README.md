# README — Guía Gamer PC Optimización

> Guía interactiva paso a paso para optimizar el rendimiento de un PC gaming con Windows 11, especialmente el HP Victus 16.

---

## ¿Qué es esta guía?

Esta guía interactiva está pensada para jugadores con un portátil gaming HP Victus —o cualquier PC gamer con Windows 11— que quieran sacar el máximo rendimiento a su equipo sin complicaciones.

Cubre las cinco herramientas más útiles para optimizar, monitorizar y controlar el rendimiento: desde las apps oficiales de HP hasta los estándares del sector gaming. Todo paso a paso, con ajustes recomendados y una tabla de temperaturas de referencia para saber cuándo preocuparse.

---

## Herramientas incluidas

| Herramienta | Para qué sirve | Compatibilidad |
|---|---|---|
| **GeForce Experience** | Drivers NVIDIA actualizados + optimización automática de juegos | PCs con GPU NVIDIA |
| **MSI Afterburner** | Control total de GPU: OC, ventiladores, overlay en juego | Cualquier marca de GPU |
| **HWiNFO64** | Monitorización avanzada de temperatura, voltaje y frecuencias | Cualquier PC |
| **HP Command Center** | Modos de rendimiento (Comfort / Default / Performance) | HP Victus y serie HP |
| **OMEN Gaming Hub** | Hub gaming completo con red, ventiladores y dashboard | HP OMEN y algunos Victus |

---

## Cómo usar la guía

La guía es una página web interactiva con cinco pestañas, una por herramienta.

### Opción A — Abrir online

1. Entra al enlace: **https://claude.ai/artifact/B5VsFvEmS7YxFGPYDXEaAQ**
2. Haz clic en la pestaña de la herramienta que quieras configurar.
3. Sigue los pasos en orden. Cada paso es independiente: puedes empezar por cualquier herramienta.
4. Usa los botones de descarga dentro de cada pestaña para ir directo a la página oficial de cada app.

### Opción B — Abrir en local (desde este repositorio)

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` directamente en tu navegador (doble clic).
3. No requiere servidor ni instalación.

> **Recomendación:** Empieza por HP Command Center (configurar el modo Performance) y GeForce Experience (actualizar drivers). Son los cambios que más impacto tienen de inmediato.

## Requisitos del sistema

- **Sistema operativo:** Windows 10 u 11 (64 bits)
- **GPU:** NVIDIA GTX/RTX (para GeForce Experience) o cualquier GPU para el resto de herramientas
- **Espacio en disco:** menos de 500 MB en total para las cinco apps
- **Conexión a internet:** necesaria solo para descargar las apps e instalar drivers
- **Hardware HP:** HP Command Center y OMEN Hub requieren un portátil HP compatible (Victus, OMEN o serie HP reciente)
