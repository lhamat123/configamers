PC Gaming · Optimization Guide

Guía Gamer PC

Configuración paso a paso de las cinco herramientas esenciales para maximizar el rendimiento de tu HP Victus y cualquier PC gaming con Windows 11.

NVIDIA · Drivers + Optimización automática

GeForce Experience

Mantiene los drivers de NVIDIA al día y ajusta automáticamente cada juego al equilibrio ideal FPS/calidad para tu GPU.

Descargar — NVIDIA.com
Instalación y configuración
01

Descarga e instala

Descarga desde nvidia.com. Requiere una cuenta NVIDIA gratuita para activarse la primera vez.

02

Actualiza los drivers

Pestaña Drivers → Buscar actualizaciones → Instalación Express. Reinicia al terminar.

03

Escanea tus juegos

Pestaña Inicio → GeForce Experience detecta automáticamente todos los juegos instalados.

04

Optimiza cada juego

Clic en un juego → botón Optimizar. Ajusta resolución, calidad de texturas y efectos al máximo FPS estable.

05

Activa el overlay

Configuración → Ajustes generales → activa Superposición dentro del juego. Alt+Z para abrirlo en partida.

Panel de Control NVIDIA — ajustes clave
Rendimiento

Gestión de energía

Administrar config. 3D → Preferir rendimiento máximo. La GPU nunca bajará de frecuencia.

FPS

V-Sync global OFF

Administrar config. 3D → V-Sync → Desactivado. Usa el V-Sync del juego si lo necesitas.

Calidad/FPS

DLSS + Reflex

En juegos compatibles, activa DLSS Quality para más FPS, y Reflex para reducir latencia de entrada.

Latencia

Low Latency Ultra

Modo de latencia baja → Ultra. Crítico en shooters y juegos competitivos online.

GPU · Control total de rendimiento

MSI Afterburner

El estándar del sector para overclocking y monitorización de GPU. Funciona con NVIDIA, AMD e Intel. Gratis y muy potente.

Descargar — MSI.com
Instala también RivaTuner Statistics Server (RTSS) — incluido en el instalador. Imprescindible para el overlay de FPS en juego.
Configuración inicial
01

Instala Afterburner + RTSS

Al instalar, deja marcada la opción de RivaTuner. Ambos deben aparecer en la bandeja del sistema.

02

Configura el overlay

Engranaje → pestaña Monitorización → marca las métricas → activa Mostrar en pantalla para cada una.

03

Curva de ventilador personalizada

Icono ventilador → activa Velocidad definida por el usuario → dibuja curva agresiva a partir de 75 °C.

04

Power Limit al máximo

Desliza Power Limit al 100% o más. La GPU deja de limitarse por consumo y libera toda su potencia.

05

Guarda el perfil

Icono 💾 → slot 1–5. Crea perfiles distintos para gaming, trabajo y silencioso, cámbialos al instante.

Métricas esenciales para el overlay
Esencial

FPS + Frametime

Los FPS muestran el rendimiento general. El frametime detecta microtartamudeos que el contador de FPS enmascara.

Esencial

Temperatura GPU

Objetivo: por debajo de 85 °C. Si sube más, ajusta la curva de ventilador o limpia el portátil de polvo.

Útil

GPU Usage %

Al 99% es perfecto — la GPU trabaja al límite. Al 50–70%, el cuello de botella está en la CPU.

Útil

CPU Usage + Temp

Uso alto en un núcleo específico = el juego depende de él. Temperatura CPU > 90 °C = señal de alerta.

Sistema · Monitorización avanzada

HWiNFO64

La herramienta más completa para ver temperatura, voltaje, frecuencia y salud de cada componente del sistema en tiempo real.

Descargar — HWiNFO.com
Puesta en marcha
01

Lanza en modo Sensors only

Al abrir, marca Sensors only → Iniciar. Verás todos los sensores del sistema directamente.

02

Localiza los sensores clave

Busca las secciones CPU, GPU y el controlador de placa. Muestra valor actual, mínimo y máximo desde el inicio.

03

Añade sensores a la bandeja

Clic derecho sobre cualquier sensor → Add to Tray para verlo siempre visible en la barra del sistema.

04

Integra con MSI Afterburner

Afterburner → Configuración → Monitorización → activa HWiNFO shared memory. Todos los sensores en el overlay del juego.

Señales de alerta en partida
Crítico

Thermal Throttling

Si CPU o GPU bajan bruscamente de frecuencia, están limitando rendimiento por temperatura. HWiNFO lo muestra en "Thermal Design Power".

Importante

CPU Package Power

En Victus con Intel, valores sostenidos >45W indican esfuerzo máximo. Normal en juegos pesados, vigilar si va acompañado de throttling.

Referencia

GPU Core Clock

Debe mantenerse estable cerca de su frecuencia boost. Fluctuaciones hacia abajo = throttling térmico o de energía.

Referencia

Battery Discharge

Un valor positivo (descargando) con cargador conectado = el adaptador no da suficiente potencia para el consumo del juego.

HP · Modos de rendimiento y temperatura

HP Command Center

La app oficial de HP para controlar los modos de rendimiento, temperatura y ventiladores del Victus directamente desde Windows.

Microsoft Store
Si no aparece en la Store, búscala en el menú Inicio — puede estar preinstalada como "HP System Event Utility".
Los tres modos explicados
ComfortSilencioso

Prioriza el silencio y la temperatura baja. Ventiladores lentos, CPU/GPU limitadas. Ideal para trabajo y navegación.

DefaultEquilibrado

Buen equilibrio entre rendimiento y ruido. Válido para juegos ligeros o uso mixto. El modo por defecto del sistema.

Performance◈ Gaming

Sin límites de consumo en CPU y GPU. Ventiladores al máximo. Úsalo solo mientras juegas — consume más batería y genera más calor.

Activar modo Performance — paso a paso
01

Abre HP Command Center

Búscala en el menú Inicio o descárgala desde la Microsoft Store si no está instalada.

02

Ve a la sección Thermal

Menú lateral → Thermal o Control de temperatura. Aquí está el selector de modos.

03

Selecciona Performance

Haz clic en Performance. Se activa al instante — no hace falta reiniciar.

04

Listo

Los ventiladores se aceleran y la CPU/GPU trabajan al máximo. Vuelve a Default al terminar de jugar para alargar la vida de la batería.

HP · Gaming Hub completo

OMEN Gaming Hub

Hub gaming completo de HP. Control de rendimiento, monitorización en tiempo real y optimización de red en una sola interfaz. Disponible en algunos modelos Victus.

Buscar en Microsoft Store
OMEN Hub está diseñado para portátiles OMEN. En el Victus puede no aparecer disponible según el modelo. Si no lo encuentras, usa HP Command Center.
Funciones principales
Rendimiento

Modos de rendimiento

Comfort, Default, Performance y en algunos modelos un modo Extreme adicional con más margen de consumo.

Ventiladores

Control manual de fans

Sube la velocidad manualmente sin depender del perfil automático. Baja la temperatura 5–10 °C en sesiones largas.

Red

Network Booster

Prioriza el tráfico del juego activo. Reduce picos de latencia en online cuando hay más dispositivos en la red.

Monitor

Dashboard en tiempo real

Temperatura CPU/GPU, uso de RAM, frecuencias y FPS del juego activo en un panel siempre visible.

Configuración recomendada para gaming
01

Activa Performance o Extreme

Panel lateral → Performance Control → selecciona el modo más alto disponible antes de lanzar el juego.

02

Fans al máximo

Fan Control → Maximum o crea curva personalizada. Los fans al máximo bajan la temperatura 5–10 °C.

03

Activa Network Booster

Network → activa el booster y selecciona el juego activo para priorizar ese tráfico en el router.

04

Vigila el Dashboard

Mantén el Hub en segundo monitor o minimizado para vigilar que la temperatura GPU no supere los 85 °C en partida.

Runtimes y DLLs esenciales
01

DirectX (DirectX End-User Runtime)

La base de los gráficos en Windows. Incluye las DLLs d3dx9_xx.dll, d3dx10_xx.dll, etc. Muchos juegos las usan aunque Windows 11 ya tenga DirectX 12 integrado. Descargar desde Microsoft →

02

Visual C++ Redistributables (todos los años)

Las librerías más olvidadas. Un juego puede fallar con VCRUNTIME140.dll not found o MSVCP140.dll. Instala el paquete "all-in-one" que incluye 2005–2022 de una vez. Paquete all-in-one →

03

.NET Framework y .NET Runtime

Muchos juegos indie y herramientas (como RivaTuner, MSI Afterburner) requieren .NET 4.8 o .NET 6/7/8. Windows Update suele instalarlo, pero si falta recibirás el error .NET Framework not installed. Descargar .NET →

04

Java Runtime (JRE / JDK)

Imprescindible para Minecraft Java Edition y servidores de mods. No viene con Windows. Error típico: 'java' is not recognized. Instala Adoptium Temurin (versión LTS gratuita). Descargar Adoptium →

05

XNA Framework (juegos antiguos / indies)

Muchos juegos indie de Xbox y Steam como Stardew Valley beta, Terraria antiguo y otros lo requieren. DLL típica: Microsoft.Xna.Framework.dll. Descargar XNA 4.0 →

06

OpenAL / OpenAL Soft (audio en juegos)

Motor de audio 3D usado en muchos FPS y RPG. Error sin él: el juego arranca sin sonido o cuelga al cargar audio. OpenAL32.dll. Descargar OpenAL →
